# Amidakuji MVP Guide

## Overview

`/amidakuji` を起点として、テンプレート選択・管理・参加者選択を行い、ランダムな役割割当を返す。

## 操作手順

1. Discord で `/amidakuji` を実行する。
2. 開始メニューで次のいずれかを選ぶ。
   - 既存テンプレートを使う
   - テンプレートを新規作成する
   - 最後に使ったテンプレートを使う
3. 既存テンプレートを選んだ場合は、次のいずれかを選ぶ。
   - 抽選へ進む
   - 編集する
   - 削除する
4. 編集する場合はテンプレート名や選択肢一覧を更新し、「更新して抽選へ進む」を押す。
5. 新規作成の場合はテンプレート名を入力後、「選択肢を追加」で1件ずつ登録する。必要に応じて「選択肢を一括編集」でまとめて調整できる。
6. 参加者を User Select で複数選択する。
7. 「抽選を実行」を押す。

## テンプレート管理

- 編集・削除は、テンプレート作成者または `Manage Guild` 権限を持つメンバーのみ利用できる。
- 削除時は確認ステップを挟む。
- 削除済みテンプレートでも、last used に保持されたスナップショットからは引き続き抽選できる。

## 抽選ルール

- Bot アカウントも抽選対象に含める。
- 対応付け件数は `min(参加者数, 選択肢数)`。
- 結果は対応付けのみ表示する。
- 抽選成功時に user x guild の last used を更新する。

## エラーハンドリング

以下は簡潔なメッセージを Discord 上に返す。

- テンプレートが存在しない
- last used が存在しない
- テンプレート名重複
- 保存失敗
- 削除失敗
- 抽選失敗
